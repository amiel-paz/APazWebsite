Seiyuu Role Profiler

Website

What is it?

Seiyuu Role Profiler is a data analytics web tool for exploring how anime voice actors' roles differ from the broader landscape of character archetypes. "Seiyuu" is the Japanese term for a voice actor, and this project represents each seiyuu through a semantic descriptor vector built from character-role metadata, LLM-extracted personality descriptors, and BAAI embedding-based similarity. Users can search for a seiyuu, see which descriptors most distinguish their roles from the average profile, inspect the characters driving that profile, and rank seiyuu by supported descriptors such as "tsundere," "stoic," or "villainous." The current static deployment supports 1,364 seiyuu profiles, focused on voice actors with substantial role activity in roughly the last 20 years, built from about 9,500 role edges, 8,000 characters, and 5,200 anime/media entries. The project emphasizes reproducible offline data processing and lightweight static serving, making the final app fast to host while preserving the modeling pipeline behind it.
